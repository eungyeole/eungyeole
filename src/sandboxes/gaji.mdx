## Git을 더 가까운 도구로

Gaji는 브랜치와 커밋, 변경 파일과 diff를 한 화면에서 살펴보는 macOS용 Git 클라이언트입니다. 네이티브 인터페이스의 손맛과 큰 저장소에서도 빠르게 반응하는 코어를 함께 다듬고 있습니다.

SwiftUI와 AppKit으로 화면을 만들고 Rust로 무거운 Git 작업을 처리합니다. 자주 반복하는 흐름을 짧게 만들면서도, 지금 저장소에서 무슨 일이 일어나는지는 선명하게 보여주는 것이 목표입니다.
