## 글 쓰는 흐름을 프로필까지

Velog에 쓴 글을 GitHub README에서 바로 소개할 수 있도록 카드 이미지로 바꿔주는 도구입니다. 프로필을 직접 고칠 필요 없이 최근 글과 활동을 한곳에 이어 보여줍니다.

작게 시작한 자동화지만, 개발자가 만드는 과정과 기록하는 과정을 자연스럽게 연결하는 방법을 실험했습니다.
