## 한 주소로 최신 글 보여주기

가장 단순한 형태는 Velog 사용자 이름만 받습니다.

```text
https://velog-readme-stats.vercel.app/api?name=eungyeole
```

이 주소는 최신 글의 제목과 설명, 태그를 하나의 SVG 카드로 만듭니다. README는 같은 이미지 주소를 유지하고, 카드의 내용은 새 글에 맞춰 갱신됩니다.

## 보여줄 글 고르기

기본값은 가장 최근 글입니다. 특정 주제의 최신 글은 `tag`로 좁히고, 한 글을 계속 보여주고 싶다면 `slug`를 지정할 수 있습니다.

```text
/api?name=eungyeole&tag=github
/api?name=eungyeole&slug=Velog-포스트로-Github를-꾸며보자
```

`tag`는 계속 쌓이는 주제에, `slug`는 오래 남겨둘 글에 어울립니다. 글을 고르는 조건이 URL에 그대로 드러나기 때문에 README 안에 별도의 설정을 둘 필요가 없습니다.

## 카드와 글을 함께 연결하기

SVG를 이미지로 넣고 `/api/redirect`를 링크로 사용하면, 카드를 클릭했을 때 같은 조건으로 선택된 글이 열립니다.

```md
[![Latest Velog post](https://velog-readme-stats.vercel.app/api?name=eungyeole&tag=github)](https://velog-readme-stats.vercel.app/api/redirect?name=eungyeole&tag=github)
```

카드가 보여주는 글과 링크가 향하는 글이 함께 바뀌므로 README에는 이 한 줄만 남습니다.

## 자리에 맞는 형태 고르기

글 하나를 강조할 때는 기본 카드, 최근 글을 모아 보여줄 때는 `/api/list`, 이름만 작게 연결할 때는 `/api/badge`를 사용할 수 있습니다.

Velog Readme Stats가 만드는 것은 새로운 통계 화면이 아니라 두 공간 사이의 연결입니다. 글은 Velog에 남고, GitHub README에는 그 글을 보여주는 작은 창만 놓입니다.
